6  NLP

Natural Language Processing (NLP) bridges the gap between text and computational models, enabling algorithms to parse, understand, generate, and extract meaningful patterns from unstructured text data.

6.1 (Pre)processing Text

Core steps in preparing raw text for natural language processing (NLP) analysis:

6.1.1 Lowercasing:

Convert all characters in the text to lowercase to ensure that words with different capitalizations (e.g., “Data”, “DATA”, and “data”) are treated as identical tokens by models.

import nltk

# Ensure necessary NLTK data is downloaded (if needed for tokenization)
nltk.download('punkt', quiet=True)

# A list of 5 iconic sentences from The Hitchhiker's Guide to the Galaxy
hitchhikers_quotes = [
    "Don't Panic.",
    "Space is big. Really big. You just won't believe how vastly, hugely, mind-bogglingly big it is.",
    "Time is an illusion. Lunchtime doubly so.",
    "The Answer to the Ultimate Question of Life, the Universe, and Everything is 42.",
    "Far out in the uncharted backwaters of the unfashionable end of the western spiral arm of the galaxy lies a small unregarded yellow sun."
]

# Lowercase the sentences using standard Python, and optionally tokenize using NLTK
lowercase_quotes = [quote.lower() for quote in hitchhikers_quotes]

# Print each lowercased sentence with its index
for i, quote in enumerate(lowercase_quotes, 1):
    print(f"{i}. {quote}")

6.1.2 Tokenization:

Split the continuous stream of text into smaller, discrete units, usually individual words, subwords, or sentences, using libraries like NLTK or spaCy.

import nltk

6.1.3 Removing Noise and Special Characters:

Strip out irrelevant elements such as HTML tags, URLs, emojis, and punctuation marks that do not add meaningful semantic value to the analysis.

import re

6.1.4 Removing Stop Words:

Filter out extremely common, high-frequency words (such as “the”, “is”, “at”, and “and”) that carry little to no substantive thematic weight.

import re
import nltk
from nltk.corpus import stopwords
from nltk.tokenize import sent_tokenize, word_tokenize

# Ensure necessary NLTK data is downloaded
nltk.download('punkt', quiet=True)
nltk.download('stopwords', quiet=True)

lowercase_quotes = [
    "don't panic.",
    "space is big. really big. you just won't believe how vastly, hugely, mind-bogglingly big it is.",
    "time is an illusion. lunchtime doubly so.",
    "the answer to the ultimate question of life, the universe, and everything is 42.",
    "far out in the uncharted backwaters of the unfashionable end of the western spiral arm of the galaxy lies a small unregarded yellow sun."
]

# 1. Tokenize into individual sentences
tokenized_sentences = []
for quote in lowercase_quotes:
    tokenized_sentences.extend(sent_tokenize(quote))

# 2. Remove noise and special characters, then tokenize into words and remove stop words
stop_words = set(stopwords.words('english'))
processed_sentences = []

for sentence in tokenized_sentences:
    # Remove special characters
    cleaned_sentence = re.sub(r'[^a-z0-9\s]', '', sentence)
    
    # Tokenize words and filter out stop words
    words = word_tokenize(cleaned_sentence)
    filtered_words = [word for word in words if word not in stop_words]
    
    # Rejoin words back into a sentence
    processed_sentences.append(' '.join(filtered_words))

# Print the final sentences with stop words removed
for i, sentence in enumerate(processed_sentences, 1):
    print(f"{i}. {sentence}")
1. dont panic
2. space big
3. really big
4. wont believe vastly hugely mindbogglingly big
5. time illusion
6. lunchtime doubly
7. answer ultimate question life universe everything 42
8. far uncharted backwaters unfashionable end western spiral arm galaxy lies small unregarded yellow sun

6.1.5 Normalization (Stemming & Lemmatization):

Reduce inflected or derived words down to their root base forms. Stemming uses crude heuristic rules to chop off word suffixes, while lemmatization uses vocabulary and morphological analysis to return the proper dictionary form (the lemma).

6.2 Text Summarization

Text summarization is a natural language processing task that uses machine learning to distill a long document into a shorter version while preserving its core meaning, key information, and overall narrative.

6.3 Topic Modeling

Topic modeling is an unsupervised machine learning technique that automatically scans documents to cluster words and uncover the hidden semantic themes or topics running through a large corpus of text.

6.4 Keywords-In-Context (KWIC)

Keywords in context (KWIC) is a text analysis technique that displays a targeted search term alongside its immediate surrounding words to help quickly examine semantic usage patterns, sentiment, and linguistic context across a large corpus.
